# Planner v0.2: dependable everyday Mac use

Approved implementation scope: preserve navigation context, separate Reopen from Undo, complete keyboard search, clarify Focus, finish native Mac commands and feedback, and repair clean-install build preparation. Preserve the compact local-first interface and existing save guards. Quick capture, hourly Week, saved views, sync, and collaboration are deferred.

## Tasks and interfaces

1. Core completion: implement `page.reopen({id, expectedRevision})` with portable restoration metadata, legacy completion-history fallback, revision guards, preservation of later edits, no restoration of deleted entries, and template cleanup. UI, assistant, and Codex use the same command. Return `PageReopenResult` with `page`, `restoredEntryCount`, `skippedEntryCount`, and human-readable `message`.
2. Interface: preserve Calendar period/day and Space tab/query/filters/groups/scroll when opening and returning from pages; nested navigation uses history. Complete search selection, matching snippets, title/label/body ranking, Escape focus restoration, and IME handling. Focus is active-only; other statuses are in All items; display Work/Due/Event dates. Replace Undo completion with Reopen and show its result. Give settings operations separate readable statuses.
3. Native/build: initialize Electron before copying required notices; provide New page/Search/Settings/Today/Back/Forward and Window menus plus menu-bar New page through a guarded renderer command path; persist and clamp window bounds. Use AppEvent type `ui-command` with data `{command: PlannerUICommand}`, where commands are `new-page`, `search`, `settings`, `today`, `back`, `forward`.
4. Acceptance: core regression tests, renderer behavior tests and fresh browser checks, native desktop smoke, packaged smoke, and build artifacts. Preserve pending external requirements for signing, real integrations, actual VoiceOver/Chinese input, Intel hardware, and signed notification delivery.

## Acceptance examples

- Filtered All items → page → Back retains the originating list and scroll; Calendar → page → Back retains period/day.
- Complete → edit writing → Reopen retains writing and restores unchanged work and chosen reminders; changed/deleted sessions and stale writes remain safe.
- Portable backup/restore and restart retain restoration data; templates clear it; repeated completion is safe.
- Reopening does not deliver stale reminders in a burst.
- Search arrows select the second result; Enter opens it; Escape returns focus; Chinese composition does not submit.
- Native menus work from a hidden window and through save guards; failed saves retain the editor buffer; offscreen bounds recover.
- Both hosted architecture jobs must complete native testing, packaging, packaged testing, and artifact upload before hosted validation is claimed.

## Constraints
